# Printer Troubleshooting Guide

## Common Symptoms
- Jobs remain stuck in the print queue.
- Printer is offline or unavailable.
- User can print to one printer but not another.
- Print quality is poor, faded, streaked, or missing pages.

## Tier-1 Checklist
1. Confirm the printer name, location, and whether the user is onsite or remote.
2. Check that the printer is powered on and connected to the network.
3. Confirm paper, toner, and any visible error messages on the printer display.
4. Ask whether other users can print to the same device.
5. Clear stuck jobs from the user's print queue if appropriate.
6. Confirm the printer is set as default when the user expects it to be.
7. Restart the printer only if it will not interrupt active business work.
8. Remove and re-add the printer from Windows settings if the queue is corrupted.

## Windows Print Spooler
If all printers fail from one Windows computer, restart the Print Spooler service:
- Open Services as an administrator.
- Locate Print Spooler.
- Select Restart.
- Ask the user to try printing a test page.

## Escalation Notes
Escalate to Desktop Support or the printer vendor if there is a hardware error code, repeated paper jams, toner replacement need, or a printer that is offline for all users.
