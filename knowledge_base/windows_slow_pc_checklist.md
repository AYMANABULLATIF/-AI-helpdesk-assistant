# Windows Slow PC Checklist

## Common Symptoms
- Laptop is slow after login.
- Applications freeze or stop responding.
- High CPU, memory, or disk usage.
- Device takes a long time to boot.

## Tier-1 Checklist
1. Ask when the slowness started and whether anything changed recently.
2. Confirm the user has restarted the computer within the last 24 hours.
3. Open Task Manager and check CPU, memory, disk, and startup app usage.
4. Check available disk space. Low disk space can cause freezing and update failures.
5. Pause unnecessary startup applications if they are not business critical.
6. Confirm Windows Updates are not actively installing.
7. Run a malware scan if behavior is unusual or browser pop-ups are reported.
8. Check whether the issue happens on battery, dock, Wi-Fi, or all conditions.

## Useful Commands
- `taskmgr` opens Task Manager.
- `winver` confirms the Windows version.
- `cleanmgr` can help remove temporary files when approved by policy.

## Escalation Notes
Escalate to Desktop Support if the device has failing hardware indicators, repeated blue screens, disk errors, severe overheating, or performance issues after the Tier-1 checklist is complete.
